### Task 4: 更新 `skills/playwright-tool/SKILL.md`

**Files:**
- Modify: `skills/playwright-tool/SKILL.md`

**Interfaces:**
- Consumes: `tools/schemas.py`
- Produces: 传授给大模型的标准工具使用流程

- [ ] **Step 1: 更新 `skills/playwright-tool/SKILL.md`**

1. 修改工具列表：明确为四大工具（`pw_page`、`pw_read`、`pw_interact`、`pw_media`）。
2. 更新标准操作流程：
   - 步骤一：`pw_page(action='open', url=...)`
   - 步骤二：`pw_read(page=1)` 或 `pw_read(keyword=...)` 或 `pw_read(refresh=True)` 阅读正文与获取 Ref ID。说明内联 Markdown 格式与 ARIA 树结构下的阅读方式。
   - 步骤三：`pw_interact(...)` 通过快照中的 Ref ID 执行精准操作。
   - 步骤四：`pw_media(...)` 视口截图、整页长图直发聊天或交付 AI 多模态理解，以及文件下载。
   - 步骤五：多标签页切换（`pw_page(action='switch_tab')`）、原生弹窗预设（`pw_page(action='dialog')`）与资源释放（`pw_page(action='close')`）。
3. 移除所有旧版 `pw_page(action='read')` / `pw_page(action='search')` 的旧示例代码。
